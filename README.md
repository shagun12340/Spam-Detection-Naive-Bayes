# 📩 Spam Detection using Naive Bayes

## 📖 Overview

This project detects whether an SMS message is **Spam** or **Not Spam** using the **Multinomial Naive Bayes** algorithm.

---

## 🚀 Features

- ✅ Single Message Prediction
- ✅ Batch CSV Prediction
- ✅ Confidence Score
- ✅ Dataset Statistics
- ✅ Pie Chart Visualization
- ✅ Download Prediction Results
- ✅ Streamlit Web Application

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes
- Matplotlib
- Joblib

---

## 📊 Model Accuracy

**97.85%**
